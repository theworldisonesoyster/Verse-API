# Easing module <B>

缓动插值函数族：为动画/关键帧运动提供速度曲线。

## Functions

| Name | Description |
|---|---|
| [Linear](linear.md) | 线性插值函数：动画匀速运动。 |
| [CubicBezier](cubicbezier.md) | 构造三次贝塞尔插值函数。 |
| [Ease](ease.md) | 缓动插值：起步慢、加速、结尾再减速（结尾略慢于开始）。 |
| [EaseIn](easein.md) | 缓入插值：起步慢，逐渐加速。 |
| [EaseOut](easeout.md) | 缓出插值：起步快，逐渐减速。 |
| [EaseInOut](easeinout.md) | 缓入缓出插值：起步慢、中间快、结尾慢。 |
