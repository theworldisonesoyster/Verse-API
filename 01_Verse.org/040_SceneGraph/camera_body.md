# camera_body class <B>

> Camera body settings, e.g. sensor/film settings, shutter speed, etc
> 相机机身设置，如传感器/胶片、快门速度等。

`using { /Verse.org/SceneGraph }`

## Members

只有数据成员，没有函数。

### Data
| Data Member Name | Type | Description |
| SensorWidthMillimeters | float | 相机传感器宽度（毫米）。 |
| SensorHeightMillimeters | float | 相机传感器高度（毫米）。 |
| SensorHorizontalOffsetMillimeters | float | 相机传感器的水平偏移。 |
| SensorVerticalOffsetMillimeters | float | 相机传感器的垂直偏移。 |
| ISO | float | 相机对光的感光度。 |
| ShutterSpeed | float | 相机快门速度。 |
