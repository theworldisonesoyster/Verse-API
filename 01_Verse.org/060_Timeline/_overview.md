# Timeline module <B>

时间线元素：把「时间点」或「时间区间」加入时间轴，驱动按时间发生的玩法。

## Classes and Structs

| Name | Description |
|---|---|
| [timeline_element](timeline_element.md) | 可加入时间线的元素的抽象定义，见 timeline_element_point 与 timeline_element_span。 |
| [timeline_element_point](timeline_element_point.md) | 占据单个时间点的时间线元素。 |
| [timeline_element_span](timeline_element_span.md) | 跨越一段时间范围的时间线元素。 |
