# Origin data <B>

相机的世界空间位置（射线起点）。这是相机眼睛点而非近裁剪面——从这里开始的检测可能撞上相机与近裁剪面之间屏幕上不可见的几何体。建议用碰撞过滤忽略玩家角色，或把起点沿 Direction 前移越过近裁剪距离。
