# Random module <S>

密码学安全的均匀随机数：随机整数/浮点与数组洗牌。

## Functions

| Name | Description |
|---|---|
| [GetRandomFloat](getrandomfloat.md) | 返回 Low 与 High 之间（含两端）均匀分布、密码学安全的随机 float。 |
| [GetRandomInt](getrandomint.md) | 返回 Low 与 High 之间（含两端）均匀分布、密码学安全的随机 int。 |
| [Shuffle](shuffle.md) | 返回一个与 Input 元素相同、但顺序已随机打乱的新数组。 |
