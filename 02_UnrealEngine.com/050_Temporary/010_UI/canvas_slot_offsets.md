# Offsets data <A>

定义控件大小与位置的偏移。锚点完整定义时，Offsets.Left 表示距 Anchors 最小 X 的像素距离、Offsets.Bottom 表示距 Anchors 最大 Y 的像素距离，从而控制期望的控件尺寸；锚点未完整定义时，Offsets.Left/Top 表示控件位置，Offsets.Right/Bottom 表示控件尺寸。
