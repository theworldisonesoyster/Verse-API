# overlay_slot struct <A>

> Slot for an overlay widget
> 叠层控件的槽位。

`using { /UnrealEngine.com/Temporary/UI }`

## Members

只有数据成员，没有函数。

### Data
| Data Member Name | Type | Description |
| [Widget](overlay_slot_widget.md) | widget | 分配到此槽位的控件。 |
| [HorizontalAlignment](overlay_slot_horizontalalignment.md) | horizontal_alignment | 控件在槽位内的水平对齐；只有在槽位布局空间创建后才生效，决定控件在该空间内的对齐。 |
| [VerticalAlignment](overlay_slot_verticalalignment.md) | vertical_alignment | 控件在槽位内的垂直对齐；只有在槽位布局空间创建后才生效，决定控件在该空间内的对齐。 |
| [Padding](overlay_slot_padding.md) | margin | 槽位内围绕控件的留白（像素）；按 1080p 分辨率计。 |
