# widget_visibility enumeration <B>

> Used by widget.SetVisibility determine how a widget is shown in the user interface.
> 由 widget.SetVisibility 使用，决定控件在界面中的显示方式。

`using { /UnrealEngine.com/Temporary/UI }`

## Enumerators

The widget_visibility 枚举包含以下枚举值：
| Name | Description |
| Visible | 控件可见并占据布局空间。 |
| Collapsed | 控件不可见且不占据布局空间。 |
| Hidden | 控件不可见但仍占据布局空间。 |
