# DetectionBeginEvent data <B>

此输入的检测已开始，例如所需按键正被按住。注意：ActivationTriggeredEvent 也可能在本帧发生，但本事件总是先触发。无论输入成功或取消，DetectionBegin 与 DetectionEnd 都会触发。元组载荷：0——玩家；1——物理输入产生的值。
