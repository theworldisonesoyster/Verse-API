# AwaitNextKeyframe function <B>

在调用处挂起，直到下一个 keyframe_delta 完成；动画被中止或未播放时也会返回。若代码需要根据 AwaitNextKeyframe 的返回原因走不同分支，参见 await_next_keyframe_result。
