## Enumerators
The play_animation_result enumeration includes the following enumerators:
| Name | Description |
| Completed | The animation completed successfully. |
| Interrupted | The animation was interrupted whilst playing. |
| Error | The animation encountered an error during initialization or whilst playing. |
