## Classes and Structs

| chat_channel(member_info) |  |
| voice_channel(member_info) | A voice_channel defines a group of agents who can communicate via voice chat. An agent can be a member of more than one voice_channel.Voice channels can accommodate 80 members of the channel's Group. Agents beyond this limit are not included in the chat.A chat participant in a voice_channel may be restricted from voice chat based on parental controls and/or user settings. |
| add_channel_error | Error returned when a channel cannot be added via the AddChatChannel function. |
| remove_channel_error | Error returned when a channel cannot be removed via the RemoveChatChannel function. |
