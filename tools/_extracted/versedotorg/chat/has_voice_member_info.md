Used to specify permissions and other settings for a voice_channel.
|  |  |
| Verse using statement | using { /Verse.org/Chat } |

## Exposed Interfaces
This interface exposes the following interfaces:
| Name | Description |
| member_info_interface | Interface that defines a class as being usable as member info in an agent group |

## Members
This interface has data members, but no functions.

### Data
| Data Member Name | Type | Description |
| CanBroadcast | ?logic | Determines if the participant can send voice messages to the channel. If true, the participant can still hear those who are broadcasting and see users in the social overlay panel. |
