## Functions
| Name | Description |
| CubicBezier | Make a cubic bezier interpolation function. |
| Linear | Linear interpolation function. Linear animations move at a constant speed. |
| Ease | Ease interpolation function. Ease animations start slowly, speed up, then end slowly. The speed of the animation is slightly slower at the end than the start. |
| EaseIn | Ease-in interpolation function. EaseIn animations start slow, then speed up towards the end. |
| EaseOut | Ease-out interpolation function. EaseOut animations start fast, then slow down towards the end. |
| EaseInOut | Ease-in-out interpolation function. EaseInOut animations are similar to Ease but the start and end animation speed is symmetric. |
