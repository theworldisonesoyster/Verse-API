Returns the quotient X/Y as defined by Euclidean division, i.e.:
- Quotient[X/Y] = Floor[X/Y] when Y > 0
- Quotient[X/Y] = Ceil[X/Y] when Y < 0
- Quotient[X/Y] * Y + Mod[X,Y] = X Fails if Y = 0.
